# Иконки расширений

`module.json.icon` — необязательный Data URL с base64: `data:image/png;base64,...`.
Поддерживаются PNG, JPEG, WebP и ICO, максимум 256 КиБ после декодирования.
Отсутствующее поле или `null` означает стандартный значок типа расширения.
SVG и внешние URL не поддерживаются. Поле входит в подпись манифеста и каталога.

В `sources.json` сохранены URL оригиналов, MIME и SHA-256. Иконки получены
2026-11-25 с сайтов провайдеров, их CDN или официального репозитория Shikimori.
Оригиналы сохранены рядом без перерисовки. Товарные знаки принадлежат владельцам;
наличие иконки не означает официальную поддержку AniMex.

AniLibria HLS использует знак AniLibria, AnimeGO Embed — знак AnimeGO,
трекер MyAnimeList (Jikan) — знак MyAnimeList, который он представляет в UI.
Для Kodik и Aksor подтверждённые иконки не найдены: `icon: null`.
Проверены домены плееров из манифестов; логотип одноимённой IDE kodik.ru
не относится к видеоплееру и не использован.

После замены оригинала обновите URL, MIME и SHA-256 в `sources.json`, затем
запустите `python scripts/update-icons.py`. Скрипт встраивает данные и повышает
patch-версию изменённых модулей. Повторный запуск без изменений ничего не меняет.
Для сборки подписанных пакетов и двух каталогов: `pwsh -NoProfile -File scripts/release.ps1`.
SDK хоста должен поддерживать `icon` до установки новых подписанных пакетов.
